# AI-Fanworks

[English](<README.md>) | 简体中文

收集各 AI 的社区二创，包括角色设计、艺术作品、提示词、制作流程及其他相关内容。

欢迎通过 Pull Request 分享你的创作。

## Contributing

提交作品时，请为自己创建独立目录，并在目录中的 README 中注明作者、参考来源（如有）及授权方式。

除此之外暂不限制具体的目录结构和内容形式。

例如，目录可以不包含作品文件，而是包含指向自有仓库或创作的链接。

## Disclaimer

本仓库为非官方的社区二次创作项目，与相关 AI 产品、项目、运营主体及公司无任何官方关联，也不代表其立场或认可。

除特别注明外，各贡献者仅代表其本人提交内容。本仓库维护者对其他贡献者提交的作品仅进行项目维护与整理，不代表对其内容、观点、来源或权利状态作出认可或保证。

贡献者应确保其有权提交和公开相关内容。

如认为仓库中的内容侵犯了你的合法权益，或认为仓库中的内容有害，请通过 Issue 联系维护者处理。
